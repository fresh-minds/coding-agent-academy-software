# Exercise 09: CI Pipeline Creation

This branch is the starting point for Exercise 09 of the Java Coding Agent Academy.

For the full baseline application context, see the [`main` branch](https://github.com/fresh-minds/coding-agent-academy-software/tree/main).

## Baseline Context

The repository contains a small Java training application with:

- Two Spring Boot 3 services: `ratings-api` and `matcher-api`
- Java 21
- A root Maven multi-module build
- Supporting local infrastructure for Kafka and MySQL

This exercise branch intentionally does not include a GitHub Actions workflow yet. Your task is to use a Coding Agent to create the repository's first minimal CI pipeline.
