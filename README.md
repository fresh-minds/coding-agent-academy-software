# Exercise 99 - Vibing Assignment

This branch is the starting point for vibe-coding a new Java Coding Agent training repository.

The goal of this exercise is to take the ideas from this academy and adapt them into a fresh training repo with a domain and structure of your own choosing.

As part of the assignment, create:

- A concise forward plan that explains the learning path and branch strategy.
- An initial repository scaffold for the new training project.
- The first two exercises of your choice, complete enough for participants to start using immediately.

Use this branch as the starting point for the assignment and shape the new repository in a way that supports realistic Coding Agent workflows.
