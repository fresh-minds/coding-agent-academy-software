# Exercise 07 - Automating Repetitive Tasks

## Objective
Use a Coding Agent to automate repetitive engineering tasks in the repo workflow.

## Starting Branch
- `exercise/07-repetitive-tasks` (branched from `main`).

## Scope
- Identify repetitive tasks (for example: local setup checks, repeated command flows, doc maintenance helpers).
- Introduce lightweight automation scripts/commands.
- Keep automation understandable and portable.

## Expected Outcomes
- Measurable reduction in manual repeated effort.
- Clear entry points (`make`, scripts, or documented command aliases).
- Automation does not hide important failures.

## Hints
- Ask agent to propose top 3 high-impact automations first.
- Prefer simple scripts over complex tooling for v1.
- Document usage and failure behavior.

## Done Criteria
- At least one practical repetitive workflow is automated end to end.
- Usage instructions are added to README/docs.
- Exercise README links to matching solution branch.

## Solution Branch Expectations
- Branch: `solution/07-repetitive-tasks`.
- README includes:
  - What was automated and expected savings.
  - Literal subagent prompt used.
  - Short rationale.
