# Exercise 09 - CI Pipeline Creation

## Objective
Use a Coding Agent to create the repository's first CI pipeline for build/test quality gates.

## Starting Branch
- `exercise/09-ci-pipeline-creation` (branched from `main`).

## Scope
- Create a basic CI workflow (build + tests).
- Keep it practical and stable for training repo needs.
- This exercise is creation-only (not CI debugging/fixing).

## Expected Outcomes
- CI runs automatically on PRs and/or pushes.
- Pipeline verifies Maven build and selected tests.
- Workflow is documented for participants.

## Hints
- Start minimal, then add one quality gate at a time.
- Keep runtime acceptable for training usage.
- Include clear failure feedback in logs.

## Done Criteria
- CI file(s) present and validated in repository context.
- README/docs explain what CI checks and when.
- Exercise README links to matching solution branch.

## Solution Branch Expectations
- Branch: `solution/09-ci-pipeline-creation`.
- README includes:
  - CI workflow summary.
  - Literal subagent prompt used.
  - Short rationale.
