# Exercise 08 - Skills and Playbooks (Agent-Agnostic)

## Objective
Learn to use reusable skill/playbook patterns so Coding Agent sessions become more consistent and efficient.

## Starting Branch
- `exercise/08-skills-playbooks` (branched from `main`).

## Scope
- Define reusable prompt/playbook patterns for recurring tasks (debugging, testing, refactor safety, review format).
- Keep core guidance tool-agnostic.
- Add optional appendix mapping patterns to specific agent ecosystems.

## Expected Outcomes
- Participants can choose and apply the right playbook for a task type.
- Prompts become more structured and reproducible.
- Session quality improves with less trial-and-error.

## Hints
- Use templates with clear sections: goal, constraints, output format, verification.
- Keep templates short and composable.
- Track when a playbook helps vs when free-form prompting is better.

## Done Criteria
- At least a small set of reusable playbooks is documented.
- One exercise demonstrates before/after quality using a playbook.
- Exercise README links to matching solution branch.

## Solution Branch Expectations
- Branch: `solution/08-skills-playbooks`.
- README includes:
  - Playbooks created and example usage.
  - Literal subagent prompt used.
  - Short rationale.
